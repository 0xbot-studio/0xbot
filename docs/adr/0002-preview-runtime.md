# ADR 0002：首版运行时边界

日期：2026-09-07
状态：实施采用

## 决定

后端锁定 Go 1.26.8，采用 chi、pgx 与官方 MCP Go SDK。初始数据库访问使用能力模块内的显式参数化 SQL；迁移使用嵌入文件、事务和 PostgreSQL advisory lock。暂不引入 sqlc/goose 工具链，避免仅为少量查询增加生成与部署依赖。后续查询规模增大时可在模块内部替换为 sqlc，不改变应用端口。迁移工具替换需要保留已应用版本记录，不重跑历史迁移。

官网采用 Next.js 静态导出，用户应用和管理端采用 Vite。三个前端及 API 分别构建镜像，部署到用户指定 VPS，复用现有 Nginx。此任务明确指定自有服务器与独立 Go API，因此不采用托管 Sites/Cloudflare 应用脚手架。

首版只开放 data.balance，使用 PublicNode 与 dRPC 的公共 Ethereum RPC，平台费用为 0，限速 60 次请求/分钟/工作区，不承诺商业 SLA。不把公共节点当作已签约商业供应商，收费前需落实商业条款及专用上游配置。

账号初期为单用户个人工作区；API 数据结构保留独立 user_id 与 workspace_id，后续扩展成员模型。管理端只开放 Provider 设置与审计，管理员需明确配置钱包名单与 TOTP。多工作区、成员、动态收费与更完整后台在后续迭代交付，不显示伪造功能。

X OAuth 流程实现并测试适配边界，真实启用依赖用户的应用配置；未配置时按钮禁用并说明原因。EOA 签名登录可独立运行。

## 代价

公共 RPC 的限流及可用性不可控；首版不具备高可用。静态页面内容在构建时更新；控制台使用实时 API。共享样式和认证展示在独立项目保留版本化副本，避免跨仓库源码依赖，后续稳定后可提取 UI 包。
