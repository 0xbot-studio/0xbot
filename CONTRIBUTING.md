# Contributing

This repository holds the platform overview, the architecture baseline
and the architecture decision records.

- Factual corrections and clarifications are welcome — open an issue or a pull request.
- ADRs follow the existing format: context, decision and consequences, with a sequential number. They record decisions that have been made, not proposals; open an issue to discuss before writing a new one.
- Application code lives in [0xbot-api](https://github.com/0xbot-studio/0xbot-api), [0xbot-app](https://github.com/0xbot-studio/0xbot-app), [0xbot-dashboard](https://github.com/0xbot-studio/0xbot-dashboard) and [0xbot-website](https://github.com/0xbot-studio/0xbot-website).
- By contributing, you agree that your contributions are licensed under Apache-2.0.
